Architecture

📐 Layered Architecture (DDD)
API Layer io.spring.api / io.spring.graphql REST controllers & GraphQL data fetchers — adapters for external communication
▼
Application Layer io.spring.application Query services, command services, DTOs, validators — orchestration & CQRS
▼
Core / Domain Layer io.spring.core Entities, repository interfaces, business services — pure domain logic
▼
Infrastructure Layer io.spring.infrastructure MyBatis mappers, repository implementations, JWT service — technical details
🧩 Design Patterns
CQRS Separate read models (QueryService + DTOs) from write models (CommandService + Entities)
Data Mapper MyBatis XML mappings decouple domain objects from DB schema
Repository Domain interfaces in core, implementations in infrastructure
DTO Projection Dedicated data classes (ArticleData, UserData) for read operations
Dual API REST + GraphQL share the same domain & application layers
Slug URL-friendly article identifiers derived from titles

Database Schema

SQLite database with Flyway migrations. 7 tables total.

Getting Started

1. Prerequisites

  • Java 11 (JDK)
  • Git
  • Docker (optional)

2. Run Locally

git clone <repo-url>
cd spring-boot-realworld-example-app
./gradlew bootRun

3. Verify

curl http://localhost:8080/tags

Should return a JSON object with a tags array.

4. GraphQL Playground

Open http://localhost:8080/graphiql in your browser for the interactive GraphQL explorer.
